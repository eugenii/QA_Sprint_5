# QA_Sprint_5

Тестируемый сайт: 'https://stellarburgers.nomoreparties.site'

### Что в проекте

Проект содержит тесты, проверяющие на вход с различных страниц сайта и переходов, связанных с аккаунтом пользователя. 

Все тестируемые элементы: кнопки, кликабельные надписи, страницы переходов - собраны в файле __locators.py__. 

Все тесты - собраны в каталоге tests в файлах:

- __test_entry.py__ - тесты, проверяющие на вход;
- __test_regisrtation_page.py__ - тесты, проверяющие на вход на страницу регистрации;
- __test_moves_from_personal_cab.py__ - тесты, проверяющие переходы со страницы личного кабинета;
- __test_scroll_items.py__ - тесты, проверяющие скролл на странице.

Фикстуры собраны в файле __conftest.py__.


### Как запустить тесты

1. Установить зависимости: `pip install -r requirements.txt`
2. Запустить тесты: `pytest -v`
